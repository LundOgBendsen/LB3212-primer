# Installation af Gitbash
[Tilbage](bash.md)


Åben i browser: https://github.com/git-for-windows/git/releases/tag/v2.14.3.windows.1

Det kan enten være en 64 bit maskine eller en 32 bit maskine.


```
https://github.com/git-for-windows/git/releases/download/v2.14.3.windows.1/Git-2.14.3-64-bit.exe

```

Dette betyder at filen **Git-2.14.3-64-bit.exe** bliver hentet og kan installeres
Kør installationen - default valg er ok
Når installation afsluttes kan man sætte kryds i start af programmet
og når programmet er startet kan man gå i proceslinien og fastgøre gitbash til proceslinien

Installationen er nu færdig
Prøv at hente **primer** fra github.


Git bash kan forstærkes lidt for at køre [gradle](../installation/gradle.md) via [sdkman](https://io.sdkman)
